# Hermes Parser AI MVP Foundation Implementation Plan

> **For Hermes:** Implement this plan task-by-task using strict RED-GREEN-REFACTOR.

**Goal:** Deliver the first executable vertical slice that converts a natural-language scraping request into a formal task, analyzes supplied site evidence, selects the fastest viable extraction strategy, and records an auditable agent run.

**Architecture:** A small dependency-free Node.js ES module core. Every agent implements the same `execute(input, context)` contract, while the orchestrator only coordinates agents and writes structured events. External AI models and browser/network probes are injected later through adapters rather than coupled to domain agents.

**Tech Stack:** Node.js 20+, ES modules, built-in `node:test`, built-in `fetch` for future probes.

## Acceptance criteria

- Natural-language examples from the brief produce a formal task.
- Strategy choice is deterministic and prioritizes APIs.
- Each agent can be replaced independently.
- Every run emits structured agent start/success/failure events.
- No generated parser or site-specific magic values are embedded in the coordinator.
- All tests pass with only Node.js installed.
