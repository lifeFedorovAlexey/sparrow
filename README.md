# Hermes Parser AI

Модульная AI-платформа для проектирования, генерации, проверки и сопровождения парсеров сайтов по описанию на естественном языке.

## Текущее состояние

Реализован визуальный вертикальный срез для статических HTML-каталогов:

1. **Task Planner** преобразует русскоязычное описание в формальную задачу.
2. **HTTP Site Probe** получает HTML, заголовки, `robots.txt`, API-подсказки, пагинацию и препятствия.
3. **Site Analyzer** нормализует наблюдения в карту сайта.
4. **Strategy Selector** выбирает REST → GraphQL → JSON → HTML → Playwright → Selenium.
5. **Hermes Orchestrator** только координирует независимые агенты и журналирует каждый шаг.
6. **DOM Analyzer** находит повторяющиеся карточки и устойчивые селекторы.
7. **Field Mapper** сопоставляет запрошенные поля с найденными элементами.
8. **Project Generator** создаёт отдельный запускаемый Node.js-проект и Dockerfile.
9. **Validator** запускает созданный парсер и проверяет количество записей, пустые поля и дубли.
10. **Visual Editor** запускает Chrome через Playwright и внедряет панель выбора DOM поверх произвольного сайта.
11. **Visual Mapping** сохраняет произвольные пользовательские имена полей без словаря и показывает JSON-предпросмотр.

API/GraphQL-генерация, браузерные стратегии, self-repair, exporters, scheduler и versioned Project Manager будут добавляться следующими срезами.

## Требования

- Node.js 20+
- npm

## Запуск визуального редактора

```bash
npm run visual
```

Откройте `http://127.0.0.1:4310`, укажите URL и нажмите «Открыть сайт». Hermes запустит управляемый Chrome с панелью поверх страницы:

1. выберите одну повторяющуюся строку или карточку;
2. кликайте по полям внутри неё;
3. задавайте произвольные названия полей;
4. проверяйте JSON-предпросмотр;
5. создайте отдельный проект парсера.

Названия полей не ограничены встроенным словарём.

## CLI (устаревающий эвристический сценарий)

```bash
npm test
npm start
```

При запуске без аргументов CLI попросит описание интерактивно:

```text
Опишите задачу парсинга:
```

Описание также можно передать одной командой:

```bash
npm start -- "Хочу получать цены с https://example.com каждые 30 минут в Telegram"
```

При успешном анализе Hermes создаёт готовый проект в `projects/<project-id>`, запускает его и сохраняет данные в `output.json`.

## Принципы

- API всегда приоритетнее браузерной автоматизации.
- Агенты заменяемы и не зависят от конкретной LLM.
- Координатор не содержит site-specific логики.
- Сетевые, LLM, storage и browser реализации подключаются через адаптеры.
- Новое поведение создаётся через RED-GREEN-REFACTOR.
